# RUMBO

Planificador personal del día. La página está en [apprumbo.online](https://apprumbo.online). La app está en [mi.apprumbo.online](https://mi.apprumbo.online).

Se entra con correo o con Google. Las tareas del día aparecen bajo Hoy. En el teléfono se puede añadir a la pantalla de inicio y pedir un aviso cuando una tarea tiene hora.
